# Kaya Social Panel — Feature Guide

A concise, non-technical feature reference for portfolio visitors. This document describes product experiences visible in the application and shared by its creator; it is not a technical specification.

| Feature | What it enables | Visibility |
| --- | --- | --- |
| Calendar | Monthly / weekly content schedule | Product overview |
| Account selection | Prepare posts for a selected connected account | Product overview |
| Post composer | Write captions, attach media, choose formats | Product overview |
| AI caption assistant | Draft captions from a prompt or uploaded image | Product overview |
| ChatGPT content workflow | Create proposed text and creative materials, then pass approved content to the panel | Product overview |
| Approval-first workflow | Keep editorial decisions with the account owner | Product overview |
| Instagram preview | Inspect content in a mobile-style preview | Product overview |
| Scheduled publishing | Organize when approved content is published | Product overview |
| Analytics dashboard | Review available account and post metrics | Product overview |
| Reporting | Review metrics and publication status | Product overview |

**Boundaries:** Other platforms displayed as “coming soon” are not listed as available integrations. Metrics shown in demonstration screenshots are snapshots, not claims about product reach or results. Screenshots and implementation materials are not included in this public document.
